# Veille concurrentielle — Simulation automobile / ADAS / véhicule autonome

Suivi quotidien de 12 concurrents du secteur : VI-grade, IPG Automotive/CarMaker, Cognata, Applied Intuition, dSPACE, CARLA, Concurrent Real-Time/SimWB, rFpro, Ansible Motion, Mechanical Simulation, Foretellix, Dynisma.

## Dernier rapport — 2026-11-12

### Résumé exécutif
- **Applied Intuition** a signé deux accords majeurs début octobre 2026 : avec **Honda** (05-06/10/2026) pour accélérer le développement de sa plateforme véhicule définie par logiciel (SDV) via Vehicle OS, et avec **Nissan** (06/10/2026), qui fait évoluer une relation historique (simulation depuis 2020) vers l'intégration de logiciels embarqués/IA native dans le véhicule — signal fort de montée en gamme d'Applied Intuition du test/simulation vers l'OS véhicule lui-même.
- **dSPACE** a enrichi sa plateforme de simulation capteurs **AURELION** avec une fonctionnalité de simulation des systèmes de surveillance du conducteur (driver monitoring), annoncée le 26/08/2026 (juste avant le précédent rapport, information non captée à l'époque) ; la version AURELION 26.1 (liée à la Release dSPACE 2026-A) est datée du 30/03/2026.
- **Correction/complément CARLA** : contrairement à ce qui avait été indiqué précédemment, une version **CARLA 0.9.16** (branche 0.9.x, distincte de la branche UE5 0.10.0) a bien été publiée le 16/09/2025, avec intégration de NVIDIA Cosmos Transfer1, support NuRec, ROS2 et usagers vulnérables de la route. Aucune nouvelle version stable n'a été identifiée depuis cette date.
- Pour la majorité des autres concurrents (**VI-grade, IPG Automotive/CarMaker, Cognata, Concurrent Real-Time/SimWB, rFpro, Ansible Motion, Mechanical Simulation, Foretellix, Dynisma**), aucune actualité fiable et clairement datée après le 28/08/2026 n'a pu être confirmée lors de cette session — voir détails et dernières informations connues par concurrent dans le rapport complet.
- Point de vigilance technique : cette session n'a pas pu accéder directement aux sites officiels (vi-grade.com, ipg-automotive.com, dspace.com, carla.org, appliedintuition.com, cognata.com, rfpro.com, etc.) par récupération directe de page — seules les recherches web indexées ont été utilisées, ce qui limite la fraîcheur de l'information pour les annonces très récentes ou non encore indexées.
